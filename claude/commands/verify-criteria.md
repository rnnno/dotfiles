現在の計画の進行状況に対して、独立検証（verifier）を実行する。

## 手順

1. **対象サブタスクを特定する。**
   - `$ARGUMENTS` が指定されていればそれを対象にする。
   - 指定が無ければ、直近でユーザーまたは自分が「完了した」と述べたサブタスクを対象にする。
   - アクティブな計画ファイル（`~/.claude/plans/` 配下、または今のセッションで承認された計画）から、対象サブタスクの**完了条件**と**検証手段**を抜き出す。見つからない/曖昧なら、ユーザーに確認する。

2. **verifier サブエージェントを起動する。**
   渡すのは**完了条件と検証手段だけ**。実装の経緯・進捗ログ・説明文は渡さない（後付け正当化を防ぐため）。

3. **判定を報告する。**
   verifier が返した3値判定（機械照合OK / 機械照合NG / 目視要）と総合判定（PASS / PASS（目視要あり） / FAIL）をそのまま提示する。

4. **FAIL の場合はループする。**
   - NG になった項目を修正する。
   - 修正後、再度この手順で `/verify-criteria` を実行する。
   - 同一サブタスクで**3回連続 FAIL** した場合はループを止め、「再計画が必要」とユーザーに伝える（パッチの繰り返しで押し切らない）。

5. **目視要が残る場合は、完了扱いにしない。**
   「目視要」の項目は未解決として明示し、ユーザーに確認を仰ぐ。黙って完了と報告しない。
